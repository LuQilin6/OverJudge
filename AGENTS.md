# OverJudge working rules

- Use English for all new communication and generated artifacts.
- Follow docs/WORKFLOW_HANDOFF.md and the current prepared stage prompt.
- Agents are replaceable through the existing file contracts. Record the actual
  tool/model/operator; do not infer identity from a default label.
- Give each A observer only its assigned POV. Use an independent D auditor.
- Actually inspect images before claiming visual review. Preserve unknowns,
  player knowledge limits and the inconclusive verdict path.
- Freeze manual outputs and verify their hashes before importing them.
- Preserve source videos and historical artifacts; use a fresh run_id for a new
  experiment. Do not overwrite another stage's accepted output.
- Use a feature branch and appropriate checks for shared changes. Publish only
  explicitly selected, reviewed artifacts; private notes and media stay local.
